# Piano gospel

Application web installable qui accompagne le cours **Piano gospel · cours pour débutants**.

- **Atelier rythme** : durées, mesures, silences, métronome, méthode de l'échelle, clic sur 2 et 4, grille, swing, 6/8, push.
- **Atelier harmonie** : clavier, portée, gammes, cercle des quintes, accords, progressions, modulation, main gauche, improvisation, vamp.
- **Atelier gospel** : oreille, chiffres de Nashville, voicings, réharmonisation, mineur, intros et fins, shout, pédale, deux mains, carnet de pratique, arpèges et runs.
- Le cours complet en PDF : `cours/Piano_gospel_cours_debutants.pdf`.

## Installer sur une tablette Android

1. Ouvrir https://elbaron86.github.io/piano-gospel/ dans Chrome.
2. Menu ⋮ → « Installer l'application ».
3. L'ouvrir une fois avec Internet : elle fonctionne ensuite hors ligne.

Tout est statique (HTML, CSS, JavaScript, Web Audio) : aucune dépendance, aucun serveur.
